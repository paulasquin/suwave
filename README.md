# Showcase kit

Template for telling a project as a single web page: scroll-driven 3D scenes ("acts"), plain sections in between, a journal with charts plotted from real data and inline 3D viewers, French and English with automatic detection, phone-friendly rendering, and a 30 s vertical video rendered from the same scenes.

Extracted from [ionic.paulasquin.com](https://ionic.paulasquin.com) (repo `paulasquin/propulseur-ionique`), which shows everything at full scale: four acts, a journal of ten experiments, the original SolidWorks parts, results and missions, and its Instagram/YouTube teaser.

Static site, no build step: three.js 0.186 via an import map, GSAP 3.15 (ScrollTrigger, SplitText) and Lenis from jsDelivr.

```bash
python3 -m http.server 8000      # then http://localhost:8000 — ?debug exposes window.__kit, ?lang=en forces English
```

## Layout

```
index.html            page skeleton; French text tagged data-i18n (default language)
css/style.css         dark space theme — tune the tokens in :root
js/main.js            wiring for this page (strings, renderers, acts, boot)
js/strings.js         project strings: ui (scripts, fr + en) and static (English of the HTML)
js/content.js         editorial content in French; content.en.js holds the English, same order/ids
js/acts/              the acts of this page (intro.js, model.js are examples)
js/kit/               reusable — normally left as is
  stage.js            one fixed WebGL canvas shared by all acts: bloom, finishing pass (vignette,
                      grain, aberration, fades), adaptive resolution, capture mode, debug GPU timer
  fx.js               QUALITY tiers, starfield, glowing plume, glow sprites, space/studio env maps,
                      layerReveal() (3D-printing reveal), Labels (HTML labels on 3D points),
                      frameOpposite() (subject opposite the card; lifted above the cards in portrait)
  page.js             Lenis + ScrollTrigger, bindActs, card panels, reveals/counters, nav,
                      lightbox, YouTube embeds, hero intro, loader, boot
  render.js           timeline, journal (lazy charts/viewers/custom visualisations), stats,
                      bar comparison (linear/log), tiles, slides
  charts.js           SVG line charts from a config, pen reveal (drivable by an act), hover read-out
  viewer.js           inline GLB viewer: solid / X-ray / section, orbit, pauses off screen
  models.js           GLB loading with meshopt; dequantises and bakes the node transform
  i18n.js             LANG, nf() number formatting, t(), registerStrings(), applyStatic(), FR/EN switch
assets/models/        GLB parts (demo.glb is generated by tools/make_demo_model.py)
tools/                asset builders and local screenshot scripts
modal/                real-GPU probes on an ephemeral Modal machine
video/                the vertical video pipeline
```

## The recipe

1. **Gather the sources.** Old blog or report (Blogger has a JSON feed: `/feeds/posts/default?alt=json&max-results=200`), photos, CAD exports, raw measurements (CSV, spreadsheets), slides. Keep working copies outside the repo (`~/scratch/<project>-src/`). Note what you cannot use (private videos, files owned by teammates) and ask before publishing other people's material.
2. **Story first.** One hero act, then two or three acts for the key moments, with plain sections between them (story, journal, results, context). Four acts is a good maximum.
3. **Assets.** `tools/build_models.py` for parts (STL/OBJ/…, units kept, base at y = 0) then `gltf-transform meshopt`; `tools/build_images.py images.json` for photos (WebP + thumbnails); a small script that turns raw CSV into a JS module for the charts (see `propulseur-ionique/tools/build_data.py`).
4. **Acts.** Copy `js/acts/model.js` as a starting point. Contract:
   ```js
   class MyAct {
     scene; camera;                       // THREE.Scene, THREE.PerspectiveCamera
     look = { bloom, bloomRadius, threshold, exposure, fade, fadeColor, vignette };
     init(renderer) {}                    // env maps, shadows (optional)
     resize(w, h) {}                      // portrait: wider fov
     setProgress(p) {}                    // 0 → 1 through the section
     update(dt, t) {}                     // per frame, only while the act is on screen
     enter() {} leave() {}                // optional (labels.hideAll() on leave)
   }
   ```
   In `index.html`, an act is `<section class="act" data-act="name">` with one `.panel` (`.panel-left`, `.panel-right`, `.panel-sticky` to hold longer) per step; split `p` by the number of panels in the act. Use wall-clock time (`performance.now()`) for intros and fades, never accumulated `dt` (slow devices stretch it). Register the act in `main.js` (`setupStage(async ({ labelsFor, manager }) => ({ name: new MyAct(…) }))`).
5. **Content and languages.** French in `index.html` and `content.js`, English in `strings.js` (`static`) and `content.en.js`. The `<head>` script picks the language before first paint: `?lang=`, then the saved choice, then `navigator.languages` (French for French speakers, English otherwise). Proofread both languages: professional tone, first person for the author, the reader addressed with "vous" if at all. An independent proofreading pass (a fresh agent) catches facts and wording that the author misses.
6. **Test.** See below — software rendering hides real bugs.
7. **Publish.** Public GitHub repo, Pages on `main` at `/`, `CNAME` file, OVH record `<sub>.paulasquin.com CNAME paulasquin.github.io.` (API keys in `~/.ovh.conf`), `gh api -X PUT repos/<repo>/pages -f cname=…`, then enforce HTTPS once the certificate is `approved` (poll `gh api repos/<repo>/pages --jq .https_certificate.state`). Add `<meta name="robots" content="noindex">` only if the site must stay out of search engines.
8. **Video.** `video/README.md`.

## Testing

- **Local screenshots** (software WebGL, slow but enough for layout): `tools/shot.py <url> <prefix> '#section@0.5' …` and `tools/shot3d.py <prefix> <act> 0 0.5 1 --url=…` (one act, UI hidden). Env `CHROME=` points to a `chrome-headless-shell` if Playwright's version is missing.
- **Real GPU** (Modal, workspace `photomate`): `MODAL_PROFILE=photomate modal run modal/gpu_probe.py --url …` (frame rates, captures; Chromium with `channel="chromium"` and `--use-angle=vulkan` gets hardware WebGL on an L4) and `modal/mobile_probe.py` (Pixel profile, GPU/CPU ms per position via `?debug`).
- **Phone**: the Android emulator on the Mac (Claude Code session `mac-guardia`, Chrome driven over CDP with `adb forward tcp:9222 localabstract:chrome_devtools_remote`). On macOS the API 36 image in "host" GPU mode shows no WebGL at all: measure with `swiftshader_indirect` (pessimistic floor). Clear Chrome's cache (`Network.clearBrowserCache`) after each deployment.

## Pitfalls already paid for

- **`pow()` of a negative base is NaN on hardware GPUs** (SwiftShader returns 0); the bloom pass then spreads it over the whole frame, which turns black. Clamp every `pow()` base.
- **Quantised GLB**: `gltf-transform meshopt` stores positions as normalised integers with a node transform; reusing `mesh.geometry` alone gives a 2-unit model. `kit/models.js` bakes it.
- **Phones pay for compositing, not only WebGL**: `backdrop-filter` on cards over the animated canvas, a full-screen animated grain, SVG with a blur filter repainted every frame. The kit disables them under 860 px; real-time shadows only on tier ≥ 1.5; big additive sprites are size-capped.
- **Hero intro frozen on Android Chrome** with `gsap.from()`: use `fromTo` with explicit end values, clear props at the end and keep a safety net (`kit/page.js` `heroIntro`).
- **GitHub Pages caches JS for 10 minutes** (max-age=600): just after a deploy, old and new modules can mix. Wait or clear the cache before concluding anything.
- **Labels off screen in portrait**: `Labels.update` flips sides at the edges; keep anchors inside the subject.
- **Mobile URL bar** resizes the viewport while scrolling: the stage ignores height changes under 150 px and ScrollTrigger runs with `ignoreMobileResize`.
- **Fonts for ffmpeg/libass**: variable fonts are not matched by style; `video/make_fonts.py` writes static instances with unique family names.
